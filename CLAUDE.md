# libcint-rs

FFI bindings and wrapper for the `libcint` C library (GTO electronic
integrals), with build-from-source support. Workspace of crates `libcint`
and `libcint-src`.

## Build and test

Tests need a pre-compiled libcint shared library. Set the following
environment variables (adjust the path to your own libcint installation)
before running `cargo test`:

```bash
CINT_DIR=<dir containing libcint.so>   # also discovered via LD_LIBRARY_PATH or REST_EXT_DIR
LD_LIBRARY_PATH=$CINT_DIR:$LD_LIBRARY_PATH
CINT_DEV=1
```

Alternatively, `cargo test --features="build_from_source"` builds the C
library from source via CMake. See `readme.md` for all environment
variables (`CINT_DIR`, `CINT_SRC`, `CINT_VIR`) and cargo features.
